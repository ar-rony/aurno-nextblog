## Introduction
Server Actions in Next.js 15 provide a powerful way to handle server-side logic directly within components. They eliminate the need for separate API routes and make data fetching and mutations simpler and more efficient.

## What are Server Actions?
Server Actions are functions that execute on the server but can be triggered directly from the client. This reduces the complexity of traditional API calls and improves performance.

### Key Benefits of Server Actions:
- **Less Boilerplate:** No need to create API routes separately.
- **Improved Performance:** Runs directly on the server, reducing client-side overhead.
- **Better Security:** Data fetching and processing stay on the server, reducing exposure.

## How to Use Server Actions in Next.js 15
Using Server Actions is simple. Let's go through a step-by-step example of fetching and updating user data.

### Step 1: Creating a Server Action
To define a Server Action, use the `"use server"` directive at the top of your function.

```javascript
'use server';

export async function getUserData() {
  const response = await fetch('https://api.example.com/user', {
    method: 'GET',
    headers: { 'Content-Type': 'application/json' }
  });
  return response.json();
}
```

### Step 2: Calling the Server Action from a Component
You can directly call the server action inside a React component.

```javascript
import { getUserData } from './actions';
import { useEffect, useState } from 'react';

export default function UserProfile() {
  const [user, setUser] = useState(null);

  useEffect(() => {
    async function fetchData() {
      const data = await getUserData();
      setUser(data);
    }
    fetchData();
  }, []);

  return (
    <div>
      <h1>User Profile</h1>
      {user ? <p>Name: {user.name}</p> : <p>Loading...</p>}
    </div>
  );
}
```

### Step 3: Updating Data with Server Actions
You can also use Server Actions to update data on the server. Let's create an action to update the user's profile.

```javascript
'use server';

export async function updateUserProfile(userId, newData) {
  const response = await fetch(`https://api.example.com/user/${userId}`, {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(newData)
  });
  return response.json();
}
```

Now, let's call this function inside a component:

```javascript
import { updateUserProfile } from './actions';
import { useState } from 'react';

export default function EditProfile({ userId }) {
  const [name, setName] = useState('');

  async function handleSubmit(event) {
    event.preventDefault();
    await updateUserProfile(userId, { name });
    alert('Profile updated!');
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Enter new name"
      />
      <button type="submit">Update Profile</button>
    </form>
  );
}
```

## Conclusion
Server Actions in Next.js 15 simplify server-side logic and improve data fetching and updates. By eliminating unnecessary API routes, they enhance security and performance while keeping the codebase clean and efficient. Start integrating them into your Next.js applications today!
