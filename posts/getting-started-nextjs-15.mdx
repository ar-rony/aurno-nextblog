## Introduction
Next.js 15 introduces several new features and optimizations that enhance performance and developer experience.

### Installation
To create a new Next.js 15 project, run:

```bash
npx create-next-app@latest my-app
```

### Key Features
- Improved Server Actions
- Enhanced RSC (React Server Components)
- Better Image Optimization

Let's explore these in detail in this guide!
